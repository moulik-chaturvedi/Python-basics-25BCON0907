# Python-basics-25BCON0907
Python Basics

This repository contains basic Python programs created as part of Session 4.

Programs
1. Factorial

The factorial.py program calculates the factorial of the number 5 using an iterative for loop.

2. Fibonacci and Student Structure

The fibonacci_and_structure.py program:

Takes the number of Fibonacci terms as input.
Generates and prints the Fibonacci series.
Defines a Student class with name, rollNo, and avgMarks attributes.
Creates a student named Rahul with roll number 101 and average marks 85.5.
3. Session 4 Program

The session_4_25bcon0907.py file contains:

A Hello message.
A factorial calculation for n = 5.
A Fibonacci series program.
A Student class containing student details.
Requirements

The programs use basic Python functionality and do not require external Python packages.

How to Run

Run the required Python file using a Python interpreter.

Example:

python factorial.py
